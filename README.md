# Fauna Indonesia 🐅

Website edukasi yang membahas berbagai jenis fauna Indonesia, manfaat fauna bagi lingkungan, ancaman terhadap satwa, dan cara pelestariannya.

## Fitur Website
- Informasi tentang fauna Indonesia
- Mengenal berbagai jenis satwa
- Manfaat fauna bagi ekosistem
- Ancaman terhadap fauna
- Informasi pelestarian satwa

## Teknologi yang Digunakan
- HTML
- CSS
- JavaScript (jika digunakan)

## Cara Menjalankan
1. Unduh atau clone repositori ini.
2. Buka file `index.html` menggunakan browser.
3. Pastikan file CSS dan gambar tersedia di lokasi yang benar.

## Tujuan
Meningkatkan pengetahuan tentang keanekaragaman fauna Indonesia dan pentingnya menjaga kelestarian satwa.

Dibuat sebagai proyek pembelajaran web development.
